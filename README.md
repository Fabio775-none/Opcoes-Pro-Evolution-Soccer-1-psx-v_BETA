# Opções-Pro-Evolution-Soccer-1-psx-v_BETA

**Desenvolvido por Fabio FJA | C++ | Windows | PlayStation 1**

Ferramenta de edição e personalização do Pro Evolution Soccer 1 (PES 1) para PlayStation 1, desenvolvida em C++ utilizando a API Win32.

O programa permite modificar parâmetros internos do jogo diretamente em arquivos BIN, por meio da alteração de offsets e valores hexadecimais, oferecendo opções que vão além das configurações tradicionais disponíveis no jogo original.

### Funcionalidades

**1. Controle de velocidade do jogo**
- Velocidade Normal
- Velocidade Máxima
- Velocidade Turbo

**2. Personalização da Master Liga**
- Alteração do dinheiro inicial para 0, 20 ou 999.
- Modificação do limite de contratações, com opções de 2 ou 255.
- Ajuste de parâmetros internos do modo Master Liga.

**3. Configurações do modo Liga**
- Alteração do tempo das partidas: 5, 10, 15, 20, 25 ou 30 minutos.
- Seleção da dificuldade: Fácil, Normal ou Difícil.

**4. Configurações da Master Liga**
- Alteração do tempo das partidas: 5, 10, 15, 20, 25 ou 30 minutos.
- Modificação da dificuldade: Fácil, Normal ou Difícil.

**5. Desbloqueio de funcionalidades**
- Opção de desbloqueio do menu de Copas por modificação de dados internos do jogo.

**6. Editor binário integrado**
- Seleção de arquivos BIN pela interface gráfica.
- Alteração direta de offsets específicos.
- Escrita de valores hexadecimais no arquivo selecionado.
- Mensagens de confirmação após as operações.

### Tecnologias utilizadas
- Linguagem: C++
- Interface gráfica: Windows API (Win32)
- Ambiente de desenvolvimento: Code::Blocks
- Compilador: GCC / MinGW
- Manipulação de arquivos binários e offsets hexadecimais

### Compatibilidade
Desenvolvido para a versão europeia do Pro Evolution Soccer 1 de PlayStation 1, identificada pelo código **SLES-03795**.
